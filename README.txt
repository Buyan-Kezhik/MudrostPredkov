ТРЕБОВАНИЯ:
- Python 3.10 или выше
- Windows 10/11

УСТАНОВКА И ЗАПУСК:

1. Установите Python с https://www.python.org/downloads/
   При установке поставьте галочку "Add Python to PATH"

2. Откройте командную строку в папке проекта

3. Установите зависимости:
   pip install -r requirements.txt

4. Создайте базу данных:
   python manage.py migrate

5. Создайте администратора:
   python manage.py createsuperuser

6. Запустите сервер:
   python manage.py runserver

7. Откройте в браузере:
   http://127.0.0.1:8000/

ПЕРЕНОС НА ДРУГОЙ ПК:
1. Скопируйте всю папку проекта
2. На новом ПК выполните шаги 1-6
3. База данных (db.sqlite3) переносится вместе с проектом

АДМИНИСТРАТОР ПО УМОЛЧАНИЮ:
- Логин: admin
- Пароль: (задаётся при createsuperuser)
